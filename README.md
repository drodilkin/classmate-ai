## 🌟 Ключевые возможности

### 📚 1. Встроенные учебники 7 класса (ФГОС)
Больше не нужно вручную фотографировать каждую страницу учебника — в приложение уже интегрированы официальные учебники:
- 🔢 **Алгебра 7 класс** — *Ю.Н. Макарычев, Н.Г. Миндюк, К.И. Нешков, С.Б. Суворова* (257 стр.)
- 🇷🇺 **Русский язык 7 класс** — *М.Т. Баранов, Т.А. Ладыженская, Л.А. Тростенцова* (249 стр.)
- 📐 **Геометрия 7–9 классы** — *Л.С. Атанасян, В.Ф. Бутузов, С.Б. Кадомцев* (417 стр.)

### 🎯 2. Автоматический поиск заданий по номеру
ИИ обучен структуре учебников и моментально сопоставляет номер задания с точной страницей PDF:
- Напишите: `номер 148 алгебра` — нейросеть откроет страницу 36 и решит уравнение с разбором.
- Напишите: `упр 89 русский` — откроет упражнение 89 на странице 54 (разбор деепричастий).
- Напишите: `задача 112 геометрия` — подгрузит условия и чертежи треугольников.

### 📸 3. Решение задач по фото (Vision)
- Сфотографируйте тетрадь, тест или доску прямо через кнопку **📷 Камера**.
- Поддержка вставки из буфера обмена (**Ctrl + V**), загрузки из галереи и перетаскивания мышью (**Drag & Drop**).
- Нейросеть распознает рукописный текст, графики, таблицы и геометрические чертежи.

### ⚡ 4. Режим «Кратко в строчку»
Спешите на уроке или нужна быстрая сверка ответа?
- Нажмите кнопку **⚡ Кратко в строчку** — нейросеть выдаст только итоговый ответ без длинных рассуждений.

### 🎙️ 5. Голосовой ввод (Speech-to-Text)
- Встроенная кнопка микрофона для быстрой диктовки условий задач на русском языке.

### 📐 6. Интерактивная шпаргалка формул
- Формулы сокращенного умножения (ФСУ), степени, свойства корней, линейные функции.
- Признаки равенства треугольников, свойства смежных и вертикальных углов, сумма углов.
- Правила написания причастий, деепричастий, корней с чередованием.
- Кнопка «Спросить у ИИ» для подробного разбора любой формулы с примерами.

### 📱 7. Нативное мобильное Android-приложение (APK)
- **Bottom Navigation Bar**: удобная нижняя панель вкладок (💬 Чат, 📚 Учебники, 📐 Формулы, ⭐ Отзывы, 👤 Профиль).
- **60–120 FPS и аппаратное GPU-ускорение**: WebView оптимизирован на уровне Android Native (`View.LAYER_TYPE_HARDWARE`), отключены веб-задержки тапов и устранен эффект «сайта внутри APK».
- **Полноэкранные экраны**: учебники и формулы открываются на весь экран смартфона с учетом вырезов под камеру (Safe Area Insets).
- **Поддержка кнопки «Назад»**: жест возврата закрывает открытые шторки и возвращает в диалог.

### 🔑 8. Вход через Яндекс ID
- Официальная авторизация через Яндекс ID в один клик.
- Сохранение истории диалогов, аватара и прогресса обучения.

### ⭐ 9. Система отзывов и рейтинг
- Реальные оценки и отзывы от учеников и родителей.
- Специальный режим создателя (**Кто оставил**) для просмотра авторов, оценок и метаданных.

### 🔥 10. Ударный режим и цель дня
- Отслеживание ежедневной серии занятий (Streak).
- Счетчик решенных заданий за день с индикатором прогресса.

## 🚀 Установка и запуск

### Запуск веб-версии для разработки

```bash
# Клонировать репозиторий
git clone https://github.com/drodilkin/classmate-ai.git
cd classmate-ai/client

# Установить зависимости
npm install

# Запустить локальный сервер
npm run dev
```

### Сборка веб-версии для продакшена

```bash
npm run build
```

---

## 📦 Сборка Android APK

Для сборки APK на компьютере должны быть установлены **Android SDK** и **Java JDK 17+**.

```bash
cd client

# 1. Сборка веб-бандла и синхронизация ресурсов
npm run build
npx cap sync android

# 2. Компиляция APK через Gradle
cd android
./gradlew assembleDebug
```

Готовый файл APK появится по адресу:  
`client/android/app/build/outputs/apk/debug/app-debug.apk`  
*(скрипт сборки автоматически копирует его в корень как `ClassMateAI.apk`)*.

### Установка на телефон через ADB:
```bash
adb install ClassMateAI.apk
```
*— или просто отправьте файл `ClassMateAI.apk` в Telegram себе на телефон и нажмите «Установить».*
